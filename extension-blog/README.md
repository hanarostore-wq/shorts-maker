# 머니OS 블로그 발행센터 v1

`shorts-maker/main` 안에서 관리하는 Manifest V3 확장프로그램이다. 기존 `extension/` 및 `extension-manus/` 상품 소싱 확장프로그램과 분리한다.

## 현재 기능

- GPT 탭에서 MONEYOS 시작·종료 블록 읽기
- 제목·본문·대상 블로그·이미지 URL·태그 파싱
- Indexed storage 기반 로컬 대기열
- 관리자 팝업의 대기열 새로고침·확장프로그램 새로고침·업데이트 확인 버튼
- 대기열 글을 새 네이버 글쓰기 탭으로 전달
- 네이버 SmartEditor 후보 입력 경로: 제목 input, iframe body, contenteditable
- 이미지 URL을 file input으로 전달하는 핵심 로직
- 발행 버튼은 v1에서 자동 클릭하지 않고 입력 결과 확인 후 사용자가 클릭

## 업데이트 방식

개발자 모드의 압축해제 확장프로그램은 브라우저 보안상 자기 파일을 스스로 교체할 수 없다. 사용자는 확장프로그램을 한 번만 로드하고, 작업 중에는 이 폴더를 계속 수정한다. 관리자 팝업의 `대기열 새로고침`은 상태를 다시 읽고, `확장프로그램 새로고침`은 런타임을 재시작한다. 개발자 모드에서 새 코드 파일을 반영할 때만 브라우저 확장프로그램 관리 화면의 새로고침 아이콘이 필요하다.

정식 배포판은 `chrome.runtime.requestUpdateCheck()`와 `version.json`을 함께 사용한다. Chrome/Whale의 정식 확장프로그램 배포 정책이 새 버전을 자동 반영하므로 사용자가 매번 다운로드할 필요가 없다. 개발자 모드에서 버튼만으로 파일 자체를 교체하는 것은 브라우저 보안상 불가능하다.

## 로컬 확인

1. `chrome://extensions` 또는 `whale://extensions` 접속
2. 개발자 모드에서 `extension-blog` 폴더를 한 번만 압축해제 로드
3. 이후 코드는 같은 폴더에 계속 수정
4. 변경 후 관리 화면의 확장프로그램 새로고침 아이콘을 한 번 눌러 코드 반영

## 현재 확인 범위

정적 구문·manifest 검증과 로컬 빌드는 가능하지만, 네이버 SmartEditor 실제 입력 성공은 로그인된 Whale/Chrome에서 확장프로그램을 최초 한 번 로드한 뒤 네이버 글쓰기 화면으로 직접 확인해야 한다. v1은 제목·본문·이미지를 입력한 뒤 자동 발행 버튼은 누르지 않는다.
