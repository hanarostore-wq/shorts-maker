# 운영본부 브라우저 — 설치하고 쓰기

개발 도구를 설치할 필요 없습니다. 설치파일을 받아서 실행하면 됩니다.

## 1. 설치파일 받기

1. https://github.com/hanarostore-wq/shorts-maker/actions 로 들어갑니다.
2. **운영본부 브라우저 설치파일 빌드** 중 초록색 체크(✓)가 붙은 가장 최근 것을 누릅니다.
3. 화면 맨 아래 **Artifacts** 칸의 `unyoung-browser-windows` 를 눌러 받습니다.
4. 받은 zip을 풀면 `unyoung-browser-setup-0.1.0.exe` 가 나옵니다.

## 2. 설치

`.exe` 를 두 번 누릅니다.

> "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보** → **실행**을 누릅니다.
> 코드 서명 인증서를 아직 붙이지 않아 나오는 경고입니다.

설치가 끝나면 바탕화면에 **운영본부 브라우저** 바로가기가 생깁니다.

## 3. 처음 켰을 때 할 일

앱을 켜면 관제실이 첫 화면으로 뜹니다. 위쪽 **⚙** 를 누르고:

| 칸 | 넣을 값 |
| --- | --- |
| Anthropic API 키 | `sk-ant-...` (console.anthropic.com 에서 발급) |
| 관제실 주소 | 비워두면 기본 배포본을 씁니다 |

**저장**을 누릅니다. 상태줄 점이 초록색이 되면 AI가 화면을 보고 판단할 준비가 된 것입니다.

키는 이 PC에만 암호화되어 저장됩니다. 다른 PC로 파일을 옮겨도 풀리지 않습니다.

## 4. 쓰는 법

1. 새 탭을 열어 쿠팡윙·스마트스토어에 **평소처럼 직접 로그인**합니다.
   에이전트는 담당자가 로그인해 둔 세션에 얹혀 일합니다. 비밀번호를 다루지
   않으며, 로그인 화면이 나오면 진행하지 않고 담당자를 부릅니다.
2. 관제실 탭의 **업무 지시** 칸에 할 일을 적습니다.
   - `"신규주문 발주확인 처리해줘"`
   - `"https://... 이 상품 수집해줘"`
3. 주소를 적지 않으면 **지금 보고 있는 탭**에서 이어서 시작합니다.

## 5. 승인

발주·결제·메시지 발송·상품 등록/수정은 **처음엔 전부 잠겨 있습니다.**
에이전트가 확정 버튼 앞에서 멈추고 관제실 **승인 대기함**에 올립니다.

담당자가 이름을 넣고 **승인**을 누르면 에이전트가 이어서 확정합니다.
승인 한 번은 그 동작 한 번만 열어 줍니다.

자주 하는 일은 **자동 승인 정책**에서 금액·건수 기준으로 열 수 있습니다.
일일 상한이 함께 걸려 있어, 임계값 아래 동작을 반복해도 하루 총액을
넘기면 다시 승인 대기로 올라갑니다.

## 문제가 생기면

| 증상 | 확인할 것 |
| --- | --- |
| 상태줄 점이 회색 | ⚙ 설정에서 API 키를 넣었는지 |
| 지시가 "실패"로 끝남 | 작업 목록의 빨간 글씨에 이유가 나옵니다 |
| 관제실이 안 뜸 | ⚙ 설정의 관제실 주소, 인터넷 연결 |
| 에이전트가 로그인 화면에서 멈춤 | 정상입니다. 해당 탭에서 직접 로그인한 뒤 다시 지시하세요 |
