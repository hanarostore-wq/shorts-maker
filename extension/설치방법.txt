소싱 마스터 PRO - 설치 방법 (크롬 / 엣지)

1. 이 압축파일을 풀어서 폴더로 만듭니다. (예: 바탕화면\소싱마스터)
2. 크롬 주소창에  chrome://extensions  를 입력해 엽니다.
   (엣지는  edge://extensions )
3. 오른쪽 위 "개발자 모드"를 켭니다.
4. 왼쪽 위 "압축해제된 확장 프로그램을 로드합니다" 를 누릅니다.
5. 1번에서 푼 폴더(manifest.json이 들어있는 폴더)를 선택합니다.
6. 주소창 옆 퍼즐 아이콘에서 "소싱 마스터"를 핀으로 고정하면 편합니다.

※ 이미 예전 버전(운영본부 상품 소싱기)을 쓰고 계시면 먼저 제거해 주세요.

─────────────────────────────────────────────
테스트해 볼 것

[소싱 탭]
 쇼핑몰 상품 상세페이지를 연 상태에서 "지금 화면 소싱하기"
 → 수집되면 관제실의 상품소싱이 직원에게 쌓입니다.
 → 수집한 가격이 마진 계산 탭의 매입가로 자동으로 넘어갑니다.

[마진 계산 탭]
 매입가/택배비/수수료를 넣으면 건당 순이익과
 "목표 100만원까지 몇 개 팔아야 하는지"가 바로 나옵니다.
 "목표 마진 판매가 적용"을 누르면 판매가가 역산되어 채워집니다.

[라이선스 탭]
 서버(Vercel)에 라이선스 기능을 배포하기 전에는
 "아직 배포되지 않았습니다" 메시지가 나오는 게 정상입니다.
 배포 후 발급한 키를 넣으면 프로로 바뀝니다.

[CSV 내보내기]
 프로 전용입니다. 무료 상태에서는 버튼이 잠겨 있습니다.

─────────────────────────────────────────────
지금 서버 상태에 따른 동작

- 라이선스 기능을 배포하지 않았다면: 예전처럼 제한 없이 소싱됩니다.
- 배포하고 LICENSE_ENFORCED=true 를 켜면: 무료는 하루 5건으로 제한됩니다.
