# Main PC 매매 실행부

- 독립 모의/실전 엔진과 데이터 디렉터리. 브라우저는 인증된 상태 조회·명령만 전송한다. 탭 종료는 stop 명령을 보내지 않는다.
- 127.0.0.1:18780, 모든 경로에 32자 이상 서버 연결키 요구. 공개 HTTPS는 Tailscale Funnel로 이 포트만 연결한다.
- 사용자 AppData/MoneyOS/trading에 별도 설치. Windows CurrentUser DPAPI와 디렉터리 ACL로 키 보호. MoneyOS-TradingWorker 로그인 시작 작업은 숨김 실행한다. 로그아웃·절전·정전 중 지속 실행을 보장하지 않는다.
- 실전 시작: 사용자 운용금 → 서버 저장 업비트 키 연결 → Jev 확인 → 업비트 실제 주문 없는 테스트 → 잔고·한도·보유분 대사 → 활성화 → 시작. 중간 정지는 후속 실행을 취소한다. 수동 주문 준비는 자동매매를 켜지 않는다.
- 기존 운영본부의 암호화 업비트 키를 서버 사이에서만 재사용한다. 원본 jev-upbit 장부는 사용하거나 변경하지 않는다.
- 안전 정지·미확정 주문은 자동 재개로 우회하지 않는다. 비정상 종료의 worker.lock은 실제 프로세스와 장부 확인 후 처리해야 한다.
- 테스트의 모의 응답 통과는 실제 계좌 주문 체결 검증이 아니다. 운영본부/PC 연결과 실제 개인 API 허용 IP를 구분한다.
