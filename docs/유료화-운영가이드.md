# 소싱 마스터 PRO - 판매 운영 가이드

확장프로그램은 **무료로 배포하고, 프로 기능만 라이선스 키로 열어주는** 방식입니다.
(크롬 웹스토어의 자체 결제는 2020년에 없어져서, 유료 확장앱은 대부분 이 방식을 씁니다.)

## 1. 환경변수 설정 (Vercel)

| 변수 | 설명 |
| --- | --- |
| `LICENSE_SIGNING_SECRET` | 키 서명용 비밀값. **한 번 정하면 절대 바꾸지 마세요** (바꾸면 이미 판 키가 전부 무효) |
| `LICENSE_ADMIN_TOKEN` | 키 발급·조회·회수 API 호출용 토큰 |
| `LICENSE_WEBHOOK_SECRET` | 결제 웹훅 서명 검증용. 결제 업체 대시보드에도 같은 값 입력 |
| `LICENSE_ENFORCED` | `true`로 두면 무료 한도가 실제로 적용됨. **비워두면 제한 없이 동작**(혼자 쓸 때) |
| `CHECKOUT_URL_PRO` / `CHECKOUT_URL_LIFETIME` | 판매 페이지의 구매 버튼이 연결될 결제 링크 |
| `SUPPORT_CONTACT` | 판매 페이지에 노출할 문의처 |

`UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN`은 키 저장에 **반드시** 필요합니다.

## 2. 파는 방법 두 가지

### (A) 수동 판매 — 오늘 바로 시작 가능
계좌이체·토스 송금을 받고 키를 직접 발급합니다. 사업자등록 전에도 시작할 수 있고,
결제 업체 심사를 기다릴 필요가 없습니다.

```bash
curl -X POST https://<도메인>/api/license/issue \
  -H "Authorization: Bearer $LICENSE_ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"plan":"pro","email":"구매자@메일","months":1,"orderId":"입금자명-날짜","memo":"토스 송금"}'
```

응답의 `license.key`를 구매자에게 보내면 끝입니다.

### (B) 자동 판매 — 결제 웹훅
결제 업체(레몬스퀴지·검로드·포트원 등) 웹훅 주소를 `https://<도메인>/api/license/webhook`으로
등록하고, 서명 비밀값을 `LICENSE_WEBHOOK_SECRET`과 똑같이 맞춥니다.
결제가 끝나면 키가 자동 발급됩니다.

- 서명: `HMAC-SHA256(본문 원문, 비밀값)`을 16진수로, `x-signature` 헤더에 담아 보냄
- 상품명/플랜에 `lifetime` 또는 `평생`이 있으면 평생 이용권으로 발급
- 같은 `order_id`로 웹훅이 두 번 와도 **키는 하나만** 나갑니다
- 환불/취소 웹훅은 자동으로 키를 없애지 않습니다 (오작동 사고 방지). 아래 회수 명령으로 직접 처리하세요

## 3. 고객 응대

```bash
# 발급 내역 보기
curl https://<도메인>/api/license/issue -H "Authorization: Bearer $LICENSE_ADMIN_TOKEN"

# PC를 바꿨다 → 그 기기만 해제 (키는 그대로 살아있음)
curl -X DELETE "https://<도메인>/api/license/issue?key=SM-...&deviceId=<기기id>" \
  -H "Authorization: Bearer $LICENSE_ADMIN_TOKEN"

# 환불했다 → 키 회수
curl -X DELETE "https://<도메인>/api/license/issue?key=SM-..." \
  -H "Authorization: Bearer $LICENSE_ADMIN_TOKEN"

# 구독 연장 (재결제 확인 후)
curl -X POST https://<도메인>/api/license/issue \
  -H "Authorization: Bearer $LICENSE_ADMIN_TOKEN" -H "Content-Type: application/json" \
  -d '{"extendKey":"SM-...","months":1}'
```

## 4. 매출 계산

| 목표 | 프로 월 19,900원 | 평생 99,000원 |
| --- | --- | --- |
| 100만원 | 51명 | 11명 |
| 월 300만원 | 151명 유지 | — |

월 구독은 한 번 모으면 다음 달에도 들어오지만, 평생권은 한 번뿐입니다.
초기에 현금이 급하면 평생권, 길게 보려면 월 구독이 유리합니다.

## 5. 시작하기 전에 확인할 것

- **통신판매업 신고**: 온라인으로 계속 판매하려면 사업자등록 + 통신판매업 신고가 필요합니다
  (연 거래 일정 규모 미만은 신고 면제 대상일 수 있으니 관할 구청에 확인하세요)
- **전자상거래법상 청약철회**: 디지털 콘텐츠도 환불 규정을 명시해야 합니다.
  판매 페이지에 7일 환불 문구를 넣어뒀습니다
- **크롬 웹스토어 심사**: 개발자 등록비 $5(1회), 심사에 보통 며칠 걸립니다
- **키 복사 방지의 한계**: 확장앱 코드는 사용자가 열어볼 수 있습니다. 그래서 무료 한도와
  프로 기능은 **서버에서** 막습니다(`/api/sourcing/scrape`). 확장앱 쪽 검사는 화면 표시용입니다
