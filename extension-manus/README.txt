머니OS 상품소싱 · Manus

설치
1. 압축을 해제합니다.
2. Chrome에서 chrome://extensions 를 엽니다.
3. 개발자 모드를 켭니다.
4. 압축해제된 확장 프로그램을 로드합니다.
5. 압축 해제한 extension-manus 폴더를 선택합니다.

사용
쇼핑몰 상품 페이지에서 확장프로그램을 열고 '지금 화면 소싱하기'를 누릅니다.
상세페이지는 현재 상품 1개, 목록페이지는 현재 화면에 표시된 상품만 수집합니다.
자동 스크롤, 무한 펼치기, 탭 자동 클릭은 사용하지 않습니다.
소싱 결과는 머니OS의 소싱관리 직원 모달에서 확인합니다.
