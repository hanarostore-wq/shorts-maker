머니OS 상품소싱 · Manus 고급판

설치
1. ZIP 압축을 해제합니다.
2. Chrome에서 chrome://extensions 를 엽니다.
3. 개발자 모드를 켭니다.
4. 압축해제된 확장 프로그램을 로드합니다.
5. 압축 해제한 extension-manus 폴더를 선택합니다.

수동 소싱
- 상세페이지: 현재 상세페이지 상품 1개만 읽기
- 목록페이지: 현재 화면에 보이는 상품 링크만 모두 소싱
- 자동 스크롤, 무한 펼치기, 탭 자동 클릭 없음
- 상품명·가격·대표/상세 이미지·옵션·재고 정보를 읽어 소싱관리 직원으로 전송

자동 소싱
1. 머니OS 상품소싱이 직원 모달에서 쇼핑몰 주소로 자동 소싱 작업을 등록합니다.
2. 확장프로그램에서 쇼핑몰 접근 권한 연결을 한 번 승인합니다.
3. 확장프로그램 워커가 상품소싱이(s1) 작업만 claim합니다.
4. 작업이 끝나면 소싱관리 직원 모달에서 상품을 확인합니다.
