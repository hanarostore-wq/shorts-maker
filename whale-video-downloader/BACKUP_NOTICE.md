# 임시 백업 안내

이 폴더는 **웨일 영상 다운로더** 저장소의 임시 백업입니다.
사용자 요청은 "새 저장소에서 작업"이었지만, 원격 세션의 GitHub 앱 권한으로는 저장소를 새로 만들 수 없어(403 "Resource not accessible by integration")
작업이 사라지지 않도록 이 세션의 작업 브랜치(`claude/charming-lamport-ad829a`)에만 올려 두었습니다. main 에는 반영하지 않았습니다.

새 저장소(예: `hanarostore-wq/whale-video-downloader`)가 만들어지면 그곳으로 옮기고 이 백업은 지웁니다.
